# GNOME Reference: Keyboard Shortcuts

## Basic Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl+W | Close tab/window |
| Ctrl+Q | Quit app |
| F1 | Help |
| F9 | Toggle utility pane |
| F10 | Open menu |
| Ctrl+? | Keyboard shortcuts dialog |
| Ctrl+, | Preferences |

## Content & Files

| Shortcut | Action |
|----------|--------|
| Ctrl+N | New |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Shift+Ctrl+S | Save As |
| Ctrl+P | Print |
| Shift+Ctrl+P | Print Preview |
| Ctrl+M | Send/Share |
| Alt+Return | Properties |

| Ctrl+A | Select All |
| Shift+Ctrl+A | Deselect All |
| Ctrl+F | Find |
| Ctrl+G | Find Next |
| Shift+Ctrl+G | Find Previous |

## Navigation

| Shortcut | Action |
|----------|--------|
| Alt+← | Back |
| Alt+→ | Forward |
| Alt+↑ | Up/Parent |
| Alt+Home | Home |
| Ctrl+L | Enter Location |
| PageUp | Previous Page |
| PageDown | Next Page |
| Ctrl+Home | First Page |
| Ctrl+End | Last Page |

## Tabs

| Shortcut | Action |
|----------|--------|
| Ctrl+T | New Tab |
| Ctrl+W | Close Tab |
| Ctrl+PageUp | Previous Tab |
| Ctrl+PageDown | Next Tab |
| Ctrl+Home | First Tab |
| Ctrl+End | Last Tab |
| Alt+1–9 | Switch to Tab 1–9 |

## Standard Navigation Keys

| Key | Function |
|-----|----------|
| Tab | Next control |
| Shift+Tab | Previous control |
| Ctrl+Tab | Next control (when Tab has other function) |
| Return | Activate focused control |
| Space | Toggle control state |
| F10 | Open primary/secondary menu |
| Menu/Shift+F10 | Open context menu |
| Esc | Close transient container |

## System Reserved (Avoid in Apps)

| Shortcut | System Function |
|----------|-----------------|
| Alt+Tab | Switch windows |
| Alt+F4 | Close window |
| Alt+F7 | Move window |
| Alt+F8 | Resize window |
| Alt+Space | Window menu |
| Ctrl+Alt+Delete | Power off |
| Super+anything | System shortcuts |
